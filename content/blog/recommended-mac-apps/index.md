## 1. QSpace Pro：把 Finder 变成真正的文件工作台

[QSpace Pro](https://qspace.awehunt.com/) 是一款保留 Finder 操作习惯、同时补足专业文件管理能力的工具。它最有价值的功能不是换一个文件浏览器皮肤，而是让多个目录可以在同一个窗口里并排显示。

QSpace 提供多种窗格布局。整理照片、迁移项目或比较两个目录时，可以直接在不同窗格之间拖放，不必反复打开 Finder 窗口再调整位置。标签页、工作区和快捷入口也能把经常使用的目录组合保存下来，下一次无需从头寻找。

它还可以浏览压缩包，并连接 FTP、SFTP、WebDAV、SMB、NFS、Amazon S3、Dropbox、OneDrive、Google Drive 等服务。对文件操作较重的用户来说，本地磁盘、NAS 与云端存储可以被放进同一套工作流里。

我会优先把它推荐给以下用户：

- 经常在多个项目目录之间复制或比较文件。
- 需要同时管理本机、移动硬盘、NAS 和云端存储。
- 觉得 Finder 太简单，但又不想重新学习一套完全不同的操作方式。

QSpace 的选项很多，刚安装时不必一次配置完。先从双窗格、标签页和常用目录开始，等遇到真实需求后再启用远程连接和自动化功能，使用体验会更轻松。App Store 版 QSpace 与官网下载的 QSpace Pro 在能力和分发方式上也有差异，购买前建议先阅读官方对比。

## 2. AltTab：用窗口预览取代“猜应用”

macOS 的 `Command + Tab` 切换的是应用，而不是应用中的每一个窗口。同一个浏览器开了多个窗口，或者某个窗口被最小化后，原生切换器常常要再配合“Command + 反引号键”、调度中心或鼠标才能找到目标。

[AltTab](https://alt-tab.app/) 把 Windows 风格的窗口切换体验带到了 Mac：按下快捷键后，可以看到各个窗口的缩略图、标题和所属应用，然后直接选中想要的窗口。对于浏览器、编辑器、终端和聊天软件同时打开的场景，这种“看见窗口再选择”的方式通常更直观。

AltTab 还可以调整缩略图尺寸、显示位置、排序方式和快捷键，也能决定是否显示最小化、隐藏或全屏窗口。它免费、开源，属于安装成本很低、又能立刻改变操作习惯的工具。

首次启动时，AltTab 会请求辅助功能与屏幕录制等权限。辅助功能权限用于激活和切换窗口，屏幕录制权限用于生成窗口预览；如果不希望提供后者，可以检查设置中是否能关闭缩略图相关能力，但体验会有所不同。

## 3. BetterDisplay：外接显示器用户的系统设置增强包

如果你给 Mac 接过 2K、4K、超宽屏或多台显示器，大概遇到过这些问题：缩放档位不合适、文字大小尴尬、显示器亮度不能用键盘调节，或者不同屏幕之间的亮度与色彩观感相差很大。

[BetterDisplay](https://github.com/waydabber/BetterDisplay) 将这些零散问题集中在一处处理。它可以提供更灵活的分辨率与缩放选项，帮助配置 HiDPI 模式；对兼容 DDC 的外接显示器，还能从菜单栏或键盘调整亮度、对比度和音量。多显示器用户也可以使用亮度同步、显示器配置与虚拟屏幕等功能。

BetterDisplay 最值得推荐的地方，是它把 macOS 原本隐藏、缺失或分散的显示设置做成了一个相对统一的控制中心。它特别适合：

- 外接显示器在默认缩放下“要么太大，要么太小”。
- 希望用 Mac 键盘控制第三方显示器亮度。
- 经常在办公室、家里和移动场景之间切换屏幕组合。
- 需要虚拟屏幕、画中画或更细致的显示器配置。

不是所有显示器都完整支持 DDC，扩展坞和转接器也可能阻断相关指令。第一次调整分辨率、刷新率或显示覆盖设置时，最好逐项尝试，并保留一个确认稳定的配置，避免一次改变太多参数后难以排查。

## 4. FineTune：给每个 App 一条独立音量推子

macOS 可以调整系统总音量，却没有内置 Windows 式的“音量混合器”。视频会议声音太小、浏览器视频突然太响、音乐又想保持在背景音量时，只能进入每个应用分别寻找设置。

[FineTune](https://github.com/ronitsingh10/FineTune) 正是用来补上这一块。它常驻菜单栏，可以分别调整每个应用的音量和静音状态，也能把较小的声音提升至最高 4 倍。更进一步，它支持将不同应用路由到不同输出设备或同时输出到多个设备，并提供 10 段均衡器、预设和 AutoEQ 耳机校正。

这类工具的魅力在于，原本混在一起的系统音频变成了可管理的通道。例如可以让会议走显示器音箱、音乐走耳机，或者单独降低浏览器而不影响播放器。对于 USB DAC、HDMI 显示器和多套蓝牙设备并存的桌面，FineTune 也能减少频繁进入系统设置的次数。

FineTune 免费且开源，但要求 macOS 15 Sequoia 或更高版本。首次启动需要授予“屏幕与系统音频录制”权限，这是识别和处理各应用音频所需的系统权限。对这类高权限工具比较谨慎的用户，可以先阅读项目源码、权限说明和故障排查文档，再决定是否长期使用。

## 5. UniGetUI：不写命令也能管理 Homebrew

[UniGetUI](https://github.com/Devolutions/UniGetUI) 最初因统一管理 WinGet、Scoop 和 Chocolatey 而在 Windows 用户中流行。如今它仍然是一款 **Windows-first** 的软件，但官方已经提供 macOS 与 Linux 构建，因此也能进入 Mac 工具箱。

在 macOS 上，UniGetUI 可以为 Homebrew、npm、Bun、pip、Cargo、.NET Tool 和 vcpkg 等包管理器提供统一的图形界面。搜索、安装、升级和卸载软件不再需要分别记住多套命令，还可以批量处理更新、查看软件包信息，以及导入或导出软件列表。

它适合已经在使用 Homebrew、但不想每天操作终端的人，也适合需要给多台机器配置相似开发环境的用户。不过，UniGetUI 的产品重心仍偏向 Windows，macOS 版的界面与系统融合度未必能达到原生 Mac App 的水准。把它理解为“多种包管理器的统一控制台”，会比把它当作 Mac App Store 替代品更准确。

> [!WARNING]
> UniGetUI 项目明确警告，`wingetui.com` 和 `unigetui.com` 是非官方网站。请通过 Devolutions 的正式渠道或 [Devolutions/UniGetUI 官方仓库](https://github.com/Devolutions/UniGetUI) 下载。通过任何包管理器安装软件时，也应核对软件包来源和发布者。

## 6. Stats：菜单栏里的 Mac 仪表盘

[Stats](https://github.com/exelban/stats) 是一款轻量、免费且开源的 macOS 系统监控工具。它可以在菜单栏显示 CPU、GPU、内存、磁盘、网络、电池和传感器等信息，点击对应模块还能查看更详细的历史或进程数据。

Stats 并不会直接让 Mac 变快，但它能帮助判断“为什么现在变慢了”：是某个进程占满 CPU，内存压力过高，网络流量异常，还是温度上升后出现性能限制。对开发、渲染、长时间导出视频或排查耗电问题的人，这种即时反馈非常实用。

菜单栏空间有限，没有必要把所有数字都常驻显示。我的建议是先保留 CPU、内存、网络和电池，再按机器与工作负载添加温度或磁盘模块。部分传感器读取会增加少量系统开销；如果只想看大致状态，可以降低刷新频率，并关闭不需要的模块。

## 7. IINA：最像现代 Mac App 的万能播放器

[IINA](https://iina.io/) 是一款基于 mpv、为 macOS 重新设计界面的免费开源播放器。它兼顾了 mpv 的格式兼容性和原生 Mac App 的操作习惯，不需要为了播放一个不常见的视频格式安装庞大的媒体套件。

除了常规的本地视频与音频播放，IINA 还支持画中画、触控板手势、字幕加载与匹配、播放列表、在线字幕和音乐模式。熟悉 mpv 的用户可以继续使用更细致的参数与配置，普通用户则完全可以把它当作开箱即用的播放器。

IINA 特别适合以下场景：

- 本地视频格式多，希望一个播放器尽量全部打开。
- 经常调整字幕延迟、音轨或播放速度。
- 想要简洁的 macOS 界面，又不想放弃 mpv 的播放能力。
- 看课程或会议录像时需要画中画和快捷键控制。

如果追求稳定，建议优先使用官网提供的正式版；只有明确需要新功能或参与测试时，再考虑 nightly build。

## 8. MacDroid：让 Android 手机出现在 Mac 的文件工作流里

Android 与 Windows 之间传文件很自然，但连接 Mac 后的体验经常不够连贯。[MacDroid](https://www.macdroid.app/) 用来简化这一步：它可以通过 MTP、ADB 或无线方式连接 Android 设备，并让用户从 Mac 访问手机中的照片、视频和文档。

它最适合经常在 Android 手机与 Mac 之间搬运大文件的人。例如把相机素材复制到 Mac 剪辑、将音乐和离线资料传回手机，或者在换机前整理重要目录。相较于每次上传网盘，它在同一张桌面上处理大量文件会直接得多。

日常传文件优先使用 MTP 即可；ADB 模式通常需要在手机上开启开发者选项和 USB 调试，权限范围更大，只应在确实需要相关能力时启用，并在公共电脑上谨慎授权。无线连接的速度和稳定性则会受到路由器、信号质量与文件数量影响，大批量传输时 USB 通常更可靠。

MacDroid 的免费版与付费版在传输方向、连接方式和完整功能上可能有所区别。安装前应先根据自己的设备和使用方式核对当前方案，避免为了偶尔传一张照片购买并不需要的功能。

## 9. Cyberduck：一个客户端连接服务器与云存储

[Cyberduck](https://cyberduck.io/) 是老牌的免费开源文件传输客户端，支持 FTP、SFTP、WebDAV、Amazon S3、Backblaze B2、Azure、Google Drive、Dropbox 等协议或服务。它的优势不是只把某一种协议做得复杂，而是用相似的书签和文件浏览体验连接多个后端。

维护网站时，可以用 SFTP 上传构建产物或修改单个配置文件；管理对象存储时，可以浏览 bucket、上传大文件并生成链接；需要访问 WebDAV 或团队云盘时，也不必为每种服务分别安装一个客户端。它还支持与系统钥匙串、外部编辑器和 Cryptomator 加密仓库配合使用。

Cyberduck 适合间歇性连接多种服务器和云存储的用户。如果工作流是持续双向同步、自动部署或处理数十万文件，专门的同步工具、命令行程序或 CI/CD 通常更合适。无论使用哪种客户端，都建议优先使用 SFTP 等加密协议，并妥善保管密钥，不要把服务器密码写进公开脚本或截图。

## 两个用于发现 Mac App 的网站

除了上面的具体应用，还有两个可以用来浏览 Mac 软件目录的网站。这里推荐的是它们的**应用发现价值**：看到感兴趣的软件后，建议记下名称，再前往开发者官网、Mac App Store 或 Homebrew 获取正式版本。

### Macked

[Macked](https://macked.app/) 收录了不同类别的 macOS 应用，适合在没有明确目标时浏览软件名称、用途和版本信息。网站当前使用 Cloudflare 验证，能否正常访问可能受到网络环境、浏览器设置和地区的影响。

### AppsTorrent

[AppsTorrent](https://appstorrent.ru/) 提供 Mac 应用、游戏和其他软件资源的分类目录。网站内容以俄文为主，不熟悉俄文时可以配合浏览器翻译，把它当作寻找应用线索的索引。

> [!CAUTION]
> Macked 和 AppsTorrent 都不是这些应用的官方分发渠道，页面中的安装包可能经过重新打包，开发者签名、完整性和授权状态也无法由本站保证。不要为了运行来源不明的软件关闭 Gatekeeper 或 SIP，也不要执行所谓“修复已损坏应用”的陌生终端命令。更安全的做法是通过这些目录发现软件，再从开发者官网、Mac App Store、Homebrew 或官方 GitHub Releases 下载，并在安装前核对开发者、代码签名与所需权限。
